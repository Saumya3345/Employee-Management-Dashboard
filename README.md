# Employee Management Dashboard

## Overview

The Employee Management Dashboard is a responsive web application developed using HTML5, CSS3, JavaScript, and Chart.js. It enables users to efficiently manage employee records through Create, Read, Update, and Delete (CRUD) operations.

## Features

- Add Employee
- Edit Employee
- Delete Employee
- Search Employee
- Department Filter
- Dashboard Statistics
- Export CSV
- Dark Mode
- Local Storage
- Interactive Chart.js Dashboard
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Local Storage API

## How to Run

1. Download the repository.
2. Open the folder.
3. Run `index.html` using Live Server.
4. Start managing employee records.
